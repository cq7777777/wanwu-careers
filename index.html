下载 Excel 模板

模板包含所有必填字段的表头，用 Excel 打开后按行填写即可。
填好后"另存为 CSV（逗号分隔）"，再回到"文件上传"标签页导入。

📖 模板字段说明：
  • 岗位名称 - 必填，如"高级前端工程师"
  • 分类 - 必填，可选：技术研发 / 产品 / 设计 / 零售 / 运营 / 人力/行政/财务 / 其他
  • 薪资 - 必填，如"25K - 40K · 14薪"
  • 地点 - 必填，如"上海"
  • 类型 - 可选，默认"全职"
  • 标签 - 多个标签用英文分号分隔，如"React;TypeScript;3年以上"
  • 描述 - 必填，岗位简介
  • 职责 - 多条用英文分号分隔
  • 要求 - 多条用英文分号分隔
